# Prospective surrogate v4 hybrid A/B

После фиксации research-v4 на коммите `6b99c75` заморожены 128 новых transfer
кандидатов вокруг champion-025. Гибрид direct/trajectory 50/50 выбрал
candidate-026 (76→87, 20%). Обе головы совпали на top, поэтому действовавший в
этом эксперименте протокол назначил случайный отличный candidate-027
(68→18, 5%) control-arm. Оба schedule и arm зафиксированы до OPM.

| direct-head control | 027 | да | 2 777 040 953,13 | +29 183,32 |

Оба OPM выполнены без кеша на одном pinned digest и завершились `sound=true`.
Candidate-026 прошёл prospective gate и стал новым champion. Его submission
прошёл selfcheck; reference-калькулятор подтвердил расчёт с
`control_start=2007-01-01`, нулём расхождений и абсолютной численной разницей
4,76837158203125e-7 ₽.

Совпадение голов выявило неэффективность случайного control-arm. После заморозки
этого эксперимента selection изменён так, чтобы будущий контроль был лучшим
отличным direct-head runner-up; текущие результаты этим изменением не затронуты.
