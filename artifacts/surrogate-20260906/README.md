# Пакет для локального поиска и экрана расчёта

Опубликован 8 сентября 2026 года вместе с веткой `feat/andrey/surrogate-release`.
`runtime.tar.gz` — около 20 МБ, 49 файлов. SHA-256 архива и каждого файла
зафиксированы в `manifest.json`. Git LFS и скачивание с компьютера автора не нужны.

В составе:

- Production-ансамбль траекторий, экономическая голова, фильтр области применимости,
  контекст признаков и указатель data/surrogate-production.json.
- Реальный базовый ответ `data/base_case/response.json` и измеренная матрица
  `data/lambda-window-2007/lambda.json`, необходимые поиску.
- Четыре каталога `out/web-runs/`: два неудачных поиска и два подтверждённых OPM
  расчёта. Сохранены условия, планы, прогнозы, наблюдения, экономика, диагностика
  и протокол проверки нового кейса. Неудачные поиски сохранены как неудачные.

Не включены повторные копии исходного deck, бинарные выходы и кеш OPM, журналы
процессов, обучающие датасеты и экспериментальные веса. Для новой проверки OPM
симуляция выполняется заново. Исторические пути в протоколах — сведения о прежнем
окружении, а не инструкции по расположению файлов на новом компьютере.

## Установка

Из корня репозитория после переключения на ветку:

```bash
python3 scripts/install_surrogate_runtime.py
```

Установщик проверяет все контрольные суммы до записи, пропускает идентичные
файлы и отказывается перезаписывать отличающиеся локальные файлы.

Нужны Python-зависимости проекта с ML (PyTorch), исходные данные организаторов
Model_Z и экономические нормативы. Эти исходники не заменяются пакетом весов.
Укажите каталог данных организаторов в `AIOS_DOCS_ROOT`, как описано в README проекта.

```bash
export AIOS_DOCS_ROOT=/absolute/path/to/docs-with-Model_Z
.venv/bin/python -m backend.presentation.cli.surrogate_check
npm --prefix frontend ci
npm --prefix frontend run build
scripts/start-surrogate-production.sh
```

Откройте `http://127.0.0.1:18080/money/constraints`: сохранённые расчёты доступны
сразу, новые запускаются кнопкой поиска. Для кнопки проверки OPM дополнительно
нужны работающий Docker и образ `openporousmedia/opmreleases:latest`.

Веса не переобучались. Известная ошибка планировщика с преждевременным урезанием
заданных дебитов остаётся: этот пакет обеспечивает воспроизводимость текущей
версии, а не исправляет её качество. Подробности — в `UNSEEN_CASE_2017.md`.
