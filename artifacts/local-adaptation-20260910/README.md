# Локальное дообучение физических моделей

Эксперимент не меняет production manifest, OOD-порог или заявляемый ЧДД.
Три члена существующего ансамбля дообучаются с learning rate 1e-4 и 3e-5,
до 30 эпох каждый. Нативный CPU: 10 потоков, без лимита памяти Docker.

Обучение: 49 целых сценариев исходного train и новые OPM-ответы 004–007,
каждый с весом четырёх сценариев (1 499 680 строк, не независимых сценариев).
Выбор весов: 10 исходных validation и 008 с весом четырёх сценариев.
009 не используется в градиентах или выборе варианта. После выбора победителя
проверяются также все 105 сценариев исходного test. Исторически эти данные могли
анализироваться: это не заявление о слепой перспективной проверке.

Исходные тензоры: `lean700/tensors_context_490_canonical.pt`, абсолютные log1p-цели,
первые 21 признаков (без scenario context). Разделение идёт по целым расписаниям,
не случайным строкам. Старые данные повторяются для ограничения забывания.

```sh
python -m backend.presentation.cli.surrogate_adapt \
  --tensors /path/to/lean700/tensors_context_490_canonical.pt \
  --runs-root out/final-campaign-20260909-01/runs \
  --out out/local-adaptation-20260910-01 --threads 10 --epochs 30

python -m backend.presentation.cli.surrogate_adapt_audit \
  --experiment out/local-adaptation-20260910-01 \
  --runs-root out/final-campaign-20260909-01/runs \
  --tensors /path/to/lean700/tensors_context_490_canonical.pt
```

`leaderboard.json` фиксирует ошибки до/после каждого варианта. `result.json`
фиксирует победителя до дополнительного аудита. `physical-audit.json` сравнивает
физические прогнозы с действующим ансамблем и проверяет историческое забывание
относительно родительской модели. Raw-network MAE и физический MAE после применения
роли скважины различаются; их нельзя смешивать в одном сравнении.

Улучшение MAE не доказывает соблюдение водного баланса или улучшение ранжирования
ЧДД. Экономическая голова этим обучением не изменяется. Перед включением новых
весов нужны дополнительные независимые OPM-пробы и проверка ограничений.

## Результат первого эксперимента

Все шесть вариантов завершены: суммарно 696,18 секунды обучения. Победитель
`member-2-lr-0.0001`, версия `e31293c85f56c0badcfffccde719152df291e1cc31ce4250fadf3643259ea923`.
Файл `research-model.pt` предназначен только для исследований, SHA-256
`71bf7265c2aa295b2b2e3c8358a3cfdb8e21fc675669f4518471a3dd41b2422c`.

На локальном отложенном 009 относительно production-ансамбля MAE нефти
19,14 → 8,01 т/скважину/интервал, давления 56,55 → 2,94 бар. Все шесть каналов
улучшились. Время оценки вместе с MAE — 0,487 → 0,260 секунды; это не время
полного поиска или построения всех признаков.

Однако на 105 исторических test-сценариях относительно родительской сети raw MAE
нефти ухудшился 10,01 → 13,06, давления 4,49 → 5,56. Ухудшились все шесть каналов.
**Эксперимент не проходит проверку сохранения качества на других режимах; в production
не включён.** Тестовые результаты не являются слепыми и не доказывают рост ЧДД.

Следующий отдельный эксперимент увеличивает replay до всех 490 старых train-сценариев,
validation до 105, использует исходный member 2, learning rate 3e-5 и 10 эпох.
Это новая гипотеза после выявления забывания, не повторная слепая проверка тех же test.

## Ограниченная интерполяция весов

Полный replay снизил историческую деградацию loss до +1,33%. Затем проверены заранее
заданные доли адаптированных весов 0,125…1,0. Правило выбора: минимальная loss на 008
при историческом отношении loss не выше 1,01. Выбрано `alpha=0.875`: историческая
loss 0,00625756 → 0,00631176 (+0,87%).

На локальном отложенном 009 относительно production-ансамбля физическая MAE улучшилась
по всем каналам: нефть 19,14 → 9,93 т/интервал, жидкость 48,69 → 14,66 м³/интервал,
закачка 277,24 → 10,87 м³/интервал, давление 56,55 → 8,45 бар. Эти метки уже были
исторически известны, поэтому модель остаётся research-кандидатом. Следующая проверка —
замороженное ранжирование новых расписаний и OPM A/B, без подстройки по их ответам.
