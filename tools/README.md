# Скрипты замеров

Разовые прогоны, которыми считались G9 и G10 21.08.2026. Не библиотека и не
часть тракта: каждый скрипт запускается из корня репозитория с `PYTHONPATH=.`
и пишет результат в `data/`.

| скрипт | что делает | стоимость |
|---|---|---|
| `g9_diff.py` | постатейное сравнение нашего плана с базовым, разложение разрыва по статьям, годам, скважинам и натуре | секунды, отклик берётся из кеша |
| `g10_pool.py` | CMA-ES тем же seed, что дал θ\*, и top-K кандидатов из истории поиска | 22 мин на 120 оценок плюс 17 с на кандидата |
| `g10_run.py` | один кандидат через звено А и настоящий OPM | 8.3 мин на кандидата |
| `g10_drive.sh` | ждёт пул и гоняет кандидатов пачками | по числу кандидатов |
| `g10_table.py` | таблица «предсказано против факта», Spearman, кривая regret | секунды |
| `g10_violations.py` | детализация нарушений динамики по скважинам и шагам | секунды, прогон из кеша |

`ab_money_loss.py` перенесён в `../to-delete/`: он упирается в то, что датасет 700
прогонов невоспроизводим текущим кодом — канон спецификации разошёлся с 17.08, все
записи кеша промахиваются по ключу, а материализованные расписания нигде не сохранены.
Условие возврата записано в `../to-delete/README.md`. Подробности —
`../../docs/v2/STATUS.md`, строка про датасет.
