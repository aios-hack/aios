# aios — трек 2

Мультиагентная система управления фондом скважин с нейросетевым суррогатом. Model_Z: 103 скважины, управление с 01.01.2007, 225 месячных шагов, цель — максимизация ЧДД.

Постановка задачи, роли, концепция и разбор материалов — в репозитории документации `aios-hack/docs`. Здесь код.

## Структура

```
contracts/                            общие типы, единственная общая поверхность
schedule/   economics/                Савелий
bridge/     surrogate/   optimizer/   Андрей
connectivity/  policy/  robustness/   Иван
ui/         llm/                      Михаил
config/
data/                                 вне git, адресуется хешами
```

Пересечений по файлам между пакетами нет: у каждого свой набор каталогов. Ветки, трогающие непересекающиеся деревья, вливаются без конфликтов.

## Правила

1. **`contracts/` правит только интегратор.** Нужна правка типа — issue, а не коммит.
2. **Каждый пишет только в своих каталогах**, даже ради однострочной правки.
3. **Зависимости по пакетам, не общим лок-файлом.**
4. **Ветки `feat/<имя>/<номер-задачи>`**, вливание через PR в защищённый `main`.
5. **Приёмка задачи — тест в своём каталоге.** Чем проверяется каждая задача, написано в её карточке в `docs/assignments/`.
6. **Моков нет.** Компонент, который не может посчитать, бросает исключение. Возврат нуля, `None` или случайного массива нужной формы запрещён. Единственное исключение — падение симулятора, оно передаётся статусом в `RunResult`.
7. **Неотвеченный вопрос организаторам — политика с реальными реализациями по каждой ветке,** а не заглушка.
8. **Производное не хранится.** Типоразмер ЭЦН, стоимости и ЧДД внутри расписания отсутствуют.
9. **`data/` в git не кладётся.** Артефакты прогонов и датасеты живут снаружи и адресуются хешами.

## С чего начать

Прочитать `contracts/README.md` целиком — там точная форма всего, что пересекает границы пакетов: единицы, порядок осей, индексация времени, инварианты.

Отдельно обратить внимание на две шкалы времени. Расписание живёт на 225 шагах от 01.01.2007, отклик симулятора — на 371 шаге от 01.11.1994, соответствие `deck_index = 146 + control_index`. Ошибка здесь не даёт ни исключения, ни абсурдного числа — она даёт правдоподобный ЧДД, посчитанный не по тем месяцам.

Затем свою карточку в `docs/assignments/`.
