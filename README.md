# aios — трек 2

Мультиагентная система управления фондом скважин с нейросетевым суррогатом. Model_Z: 103 скважины, управление с 01.01.2007, 225 управляющих шагов при 224 наблюдаемых интервалах, цель — максимизация ЧДД.

Постановка задачи, роли, концепция и разбор материалов — в репозитории документации `aios-hack/docs`. Здесь код.

## Структура

```
contracts/                            общие типы, единственная общая поверхность
schedule/   economics/                Савелий
bridge/     surrogate/   optimizer/   Андрей
connectivity/  policy/  robustness/   Иван
ui/         llm/                      Михаил
config/                                Иван
data/                                 вне git, адресуется хешами
```

Корневые файлы вне этой схемы (`Dockerfile`, CI, общий `README.md`) — тоже за Савелием как интегратором: они пересекают все четыре пакета, значит не могут принадлежать ни одному из них по правилу 2 ниже. Задачи 54 (Docker-образ) и 55 (документация) — его, не Ивана: раньше числились за Иваном, хотя `Dockerfile`/корневая документация вне его каталогов и правило 2 ему это запрещает.

Пересечений по файлам между пакетами нет: у каждого свой набор каталогов. Ветки, трогающие непересекающиеся деревья, вливаются без конфликтов.

## Правила

1. **`contracts/` правит только интегратор — Савелий.** Владеет самым потребляемым контрактом (`Schedule`, экономика) и стартует первым без OPM, поэтому держит общую поверхность. Нужна правка типа — issue, а не коммит.
2. **Каждый пишет только в своих каталогах**, даже ради однострочной правки.
3. **Зависимости по пакетам, не общим лок-файлом.**
4. **Ветки `feat/<имя>/<номер-задачи>`**, вливание через PR в защищённый `main`.
5. **Приёмка задачи — тест в своём каталоге.** Чем проверяется каждая задача, написано в её карточке в `docs/assignments/`.
6. **Моков нет.** Компонент, который не может посчитать, бросает исключение. Возврат нуля, `None` или случайного массива нужной формы запрещён. Единственное исключение — падение симулятора, оно передаётся статусом в `RunResult`.
7. **Неотвеченный вопрос организаторам — политика с реальными реализациями по каждой ветке,** а не заглушка.
8. **Производное не хранится.** Типоразмер ЭЦН, стоимости и ЧДД внутри расписания отсутствуют.
9. **`data/` в git не кладётся.** Артефакты прогонов и датасеты живут снаружи и адресуются хешами.

## С чего начать

Прочитать `contracts/README.md` целиком — там точная форма всего, что пересекает границы пакетов: единицы, порядок осей, индексация времени, инварианты.

Отдельно обратить внимание на две шкалы времени. Расписание живёт на 225 управляющих датах от 01.01.2007 (`deck_date_index = 146 + control_step`), но замкнутых интервалов из них только 224 — у последней даты (01.09.2025) нет следующей в деке, значит и наблюдаемого месяца. Отклик симулятора — на 371 шаге от 01.11.1994. Ошибка здесь не даёт ни исключения, ни абсурдного числа — она даёт правдоподобный ЧДД, посчитанный не по тем месяцам. Полная форма — `contracts/README.md` §1.2.

Второе: расписание внутри управляющего горизонта — не только режимы фонда. 25 блоков `COMPDATMD`, один `WPIMULT` и ввод 22 скважин, ранее не появлявшихся в `WCONPROD`/`WCONINJE`, лежат **после** 01.01.2007 и переносятся в `wells_schedule.inc` как есть — это данные месторождения, не решения агента. Форма — `contracts/README.md` §2.

Затем свою карточку в `docs/assignments/`.
