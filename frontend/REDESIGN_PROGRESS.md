# Реструктуризация: прогресс очереди R

Единственное место, где живёт статус R-задач до переноса в `../docs/v2/STATUS.md`.
Значения: пусто — не начата, `в работе`, `готово` (приёмка выполнена зелёным тестом),
`заблокировано` с причиной.

Правило: `готово` без зелёного теста и проходящего `npm run build` не ставится.

## Волны

Волна — набор задач без пересечения файлов, выполняемых параллельно.

## Внешние блокеры (не фронтовые, но обесценивают результат)

Из `REDESIGN.md` §9. Ни одна задача R их не чинит — это работа интегратора.

| | Что | Кому | Почему критично |
|---|---|---|---|
| КС3 | Измеренная λ не выгружена в витрину: `graph.json` синтетический (181 ребро, устойчивость 0.74) вместо замера `5261e17` (1122 ребра, 0.993) | интегратор, `ui/` | Морфинг F3 — главный козырь — доказывает тезис на выдуманной связности |
| КС4 | В `api/types.ts` нет признака валидации прогона | интегратор | Зелёный чип на прогоне вроде G7 (1628 нарушений) соврал бы жюри |
| КС5 | `frontend/public/data/` не в git и не в образе | не назначено | На чистом клоне витрина не воспроизведётся у организаторов |
| D2 | В бандле `provenance: synthetic-demo`, ЧДД 141 177 руб | интегратор | Предусловие F11–F16 формально нарушено |

## Проверка после каждой волны

```bash
cd aios/frontend
npx --yes node@22.11.0 node_modules/vitest/vitest.mjs run
npm run build
```

Плюс грепы-гейты, накопительно:

```bash
grep -rn ":has(" src/                    # R1: пусто
grep -rn "chronomap-legend\|wall-legend" src/   # R9: пусто
grep -rn "radius-pill\|translateY(-2px)" src/   # F1: пусто (регресс-гейт)
```

Плюс скриншоты Playwright (`playwright-core` + `channel: 'msedge'`, браузеры не скачиваются)
на 1366×768 и 1920×1080 — проверка, что контент не уехал за фолд.
