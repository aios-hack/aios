# Реструктуризация консоли: макеты и карта миграции

Парный документ к `REDESIGN.md` (диагноз, целевая модель, очередь R). Здесь — покадровые макеты
каждого пространства, миграция каждого нынешнего элемента экрана, поведение инспектора и оси
времени, клавиши и изменения токенов. Все макеты — про компоновку, не про пиксели: размеры даны
как ориентиры и берутся из токенов, не из литералов.

Обозначения: `[Кнопка]` — интерактивный элемент, `⚙` — поповер «Настройка вида», `◇` — слот
легенды, `▸` — раскрытие. Величины в макетах условные.

---

## 1. Постоянный каркас

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ ЛОГО  AIOS · Model_Z      [Прогноз суррогата · демо-данные]   [СЦЕНАРИЙ base]│
│                                                        [Демо] [Тема] [RU|EN] │ ← header 48
├──────────────────────────────────────────────────────────────────────────────┤
│ Отбор ~161к ▁▂▂▃ │ Закачка 91к ▂▃▄ │ Компенсация 60% ▄▃▂ │ ЧДД 2.6к ▁▂▄ │ 81 │ ← strip 88
├────────┬──────────────────────────────────────────────────────┬──────────────┤
│ 1 Поле │  строка инструментов пространства            ◇  ⚙   │              │
│ 2 Ист. │                                                      │  Инспектор   │
│ 3 Реш. │                  СЦЕНА                               │  (по вызову) │
│ 4 День.│                                                      │              │
├────────┴──────────────────────────────────────────────────────┴──────────────┤
│ 2007────2010────2013────2016────2019────2022────2025   ·засечки событий·     │
│ [⏮][▶][⏭]  ─────────●────────────────  [1×|4×|16×]   январь 2007 · шаг 1/225 │ ← timeaxis 96
└──────────────────────────────────────────────────────────────────────────────┘
```

Grid-areas (R1): `header / strip / nav scene inspector / timeaxis`. Колонка `nav` узкая
(текстовые пункты, ~120px), `inspector` — `var(--size-card-max)`, схлопывается в 0 когда закрыт.
Никаких `:has()` — открытость инспектора задаёт класс/атрибут на контейнере сетки.

Почему навигация слева, а не строкой сверху: на экране 16:9 дефицитна высота, а не ширина —
шапка, лента и ось уже съедают ~230px, и каждая дополнительная строка отнимает у хронокарты
и стены жизней место под 103 строки фонда. Вертикальная колонка меняет избыточную ширину на
дефицитную высоту. Запасной вариант, если колонка не согласуется, — верхний сегмент на месте
нынешнего переключателя сцен; тогда строка инструментов пространства объединяется с ним и
бюджет её контролов сокращается до 5.

Что исчезло из постоянного каркаса по сравнению с текущим экраном:

- шесть индикаторов табло доверия → статус-чип (см. §2);
- нижняя строка целиком: иконка демо (→ шапка), табы «Сценарии | Вклад в ЧДД» (→ пространство
  «Деньги»), бейдж сценария (→ шапка);
- кнопка «Показать таблицу фонда» (→ «История», взгляд «Таблица»);
- вторая строка контролов сцены (ползунки) → ⚙.

## 2. Шапка и статус-чип доверия

Слева направо: лого+название (как есть) · статус-чип · бейдж сценария · [Демо] · тема · язык.
Шесть элементов, из них интерактивных пять.

Синтез статус-чипа (R4), первый сработавший сверху вниз:

| Условие | Текст чипа | Тон |
|---|---|---|
| `provenance = synthetic-demo` | Демо-данные · не для выводов | янтарный |
| `final_npv` заполнен, валидация прогона чистая | Подтверждено OPM · прогон <id> | зелёный |
| `final_npv` заполнен, есть нарушения валидации или признака нет | Прогон OPM · число не заявляемо | янтарный |
| `ood_score` выше порога | Прогноз · вне домена, отправлен на ГГДМ | янтарный |
| `converged = false` или `self_consistent = false` | Прогноз · неподвижная точка не сошлась | янтарный |
| нужное поле отсутствует | Прогноз · не измерено: <поле> | янтарный |
| иначе | Прогноз суррогата · в домене | нейтральный |

Признака валидации прогона в `api/types.ts` сейчас нет — его надо запросить у интегратора
(случай реален: G7 — Flow `OK`, но 1628 нарушений `validate_dynamic`, число не заявляемо).
До появления поля `final_npv` без признака даёт янтарный чип, не зелёный.

Клик по чипу — поповер с полным табло F8 (все шесть строк, значения и «не измерено»,
`SyntheticBanner` как строка происхождения). Никакой информации не теряется — теряется её
постоянное присутствие в шапке.

## 3. Лента поля и главный график

Лента — пять карточек как сейчас (спарклайн + значение, коридор нормы у компенсации).
Добавляется одно поведение: клик по карточке разворачивает под лентой полосу главного графика
(F6: накопленный ЧДД + месячная добыча, две сложенные панели с общей осью, курсор синхронен оси
времени). Повторный клик или Escape сворачивает. Развёрнутая полоса прижимает сцену, не
перекрывает её.

```text
├──────────────────────────────────────────────────────────────────┤
│ ▸ Накопленный ЧДД, руб.                                 [закрыть]│
│   ┌────────────────────────────────────────────────────────────┐ │
│   │ накопленный ЧДД ───────────────╱────────                   │ │
│   │ добыча за месяц ▂▃▃▂▁▂▃▄▃▂▁          │ курсор = тек. шаг   │ │
│   └────────────────────────────────────────────────────────────┘ │
```

## 4. Пространство «Поле» (дефолт)

```text
│ [Связность|Карта]  Величина: [Обводнённость ▾]  Пласт: [Все ▾]   ◇  ⚙ │
│                                                                        │
│                      ● ● ▼   ●  ◌                                      │
│                    ●  ▼  ● ●   ●     ← сцена на всю область            │
│                      ●   ● ▼ ●                                         │
│                                                                        │
```

- **Дефолт — «Связность»**: по контракту §12.3 главный вид — граф влияния, карта вторым
  (центральный тезис заказчика: близость ≠ гидродинамическая связь). Сейчас приложение
  открывается картой — это расхождение с решением от 13.08, чинится сменой дефолта.
- Сегмент «Связность|Карта» запускает морфинг F3 (1.2–1.5с, reduced-motion — мгновенно).
- «Величина» — кодировка заливки из F2: обводнённость / вклад в ЧДД / факт-цель.
- «Пласт» — фильтр из контракта §12.4, возвращается задачей R14 (потерян при переходе
  с `FieldMap` на `FieldProjection`); невыбранный пласт приглушается, не скрывается.
- ⚙: ползунок перехода (точное `t`), порог λ, показ невведённых.
- ◇ легенда: рампа величины, форма=роль, счётчик «связей N/M», «22 без связности»,
  окно измерения λ — всё в одном месте.
- Клик по скважине → инспектор + связное выделение (соседи по λ, группа) — как сейчас.
- Резерв F12: тогл «Сравнить с базой» добавится сюда, когда появится собственный план —
  шторка по карточке F12 живёт на сцене; числовой итог сравнения — в «Деньгах».

Контролов в строке: 5. (Сейчас у проекции: 2 сегмента + 2 ползунка + счётчик + отдельные
подписи по углам.)

## 5. Пространство «История»

```text
│ [Матрица|Миниатюры|Таблица]  Величина: [Обводнённость ▾]  Сортировка: [По участку ▾]  ◇ ⚙ │
│                                                                                            │
│   строки=скважины ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓░░                                               │
│                   ▓▓▓▓▓▓▒▒▒▒▒▒▒▒▒▒▒▒▓▓▓▓▓░░   │ вертикаль = текущий шаг                    │
│                   ▓▓▓▓▓▓▓▓▓▓▒▒▒▒▒▒▒▒▒▒▒▒▒░░                                                │
```

- «Матрица» — Chronomap (F4), «Миниатюры» — WallOfLives (F14), «Таблица» — нынешний `WellsTable`
  из StepsBlock. Три взгляда на один объект: фонд × время.
- Величина и сортировка — общие, живут в состоянии пространства, переживают переключение взгляда.
  Наборы значений объединяются (матрица: обводнённость/режим/факт-цель/вклад; сортировки: номер/
  участок/вклад/обводнённость на последнем шаге). Недоступное для взгляда значение — задизейблено
  с причиной, а не исчезает.
- ⚙: плотность строк, показ невведённых, у миниатюр — высота ряда.
- ◇: рампа, «размер 103×225» (из данных), примечания кодировки.
- Клик ячейки/миниатюры/строки: скважина + шаг → инспектор, синхронно во всех взглядах.

## 6. Пространство «Решения»

```text
│ [Совет|Правила]                                                   ◇ ⚙ │
│                                                                        │
│  МЕНЕДЖЕР ПОЛЯ   лимит 2 615.8 ─ G1 32.6% ─ G3 35.7% ─ G5 31.7%        │
│  ─────────────────────────────────────────────────────────────         │
│  УЧАСТКИ   [G1 853.8] [G3 932.6] [G5 829.4] …                          │
│  ─────────────────────────────────────────────────────────────         │
│  ИСПОЛНИТЕЛИ · G1   скважина · решение · правило · ограничение         │
```

- «Совет» — нынешний Council (F11) без изменений содержимого; выбор скважины подсвечивает путь
  исполнитель → участок → поле (уже реализовано).
- «Правила» — ablation-таблица F15 (перенос из NpvRank решается в R7/R11; аргумент за перенос —
  это ответ «почему правила работают», т.е. про решения, не про деньги).
- Трасса конкретного решения остаётся в инспекторе скважины — здесь иерархия, там объяснение.

## 7. Пространство «Деньги»

```text
│ [Рейтинг ЧДД|Сравнение|Ограничения]                                ⚙ │
│                                                                       │
│  Рейтинг: таблица вкладов по скважинам (NpvTable), режим налога       │
│  Сравнение: ScenarioComparison + библиотека сценариев; резерв F12     │
│  Ограничения: ConstraintsEditor; резерв F16 (цена ограничения)        │
```

- Всё содержимое существует сегодня в двух нижних панелях — меняется только дом и разрезка стека
  на под-табы.
- Над рейтингом — постоянное место главного графика F6 (накопленный ЧДД + добыча): главный
  временной ряд приложения не может жить только за кликом по ленте (см. `REDESIGN.md` §6.3).
- «Ограничения» сохраняют кнопки «Скачать JSON / Загрузить JSON» — это контрактное свойство
  (§6.3, [Онб.12]: интерфейс порождает документ, а не только читает); их потеря при переезде —
  регресс, проверяется приёмкой R7.
- Выбор сценария в библиотеке меняет `ScenarioContext`; бейдж в шапке обновляется; сравнение
  двух демо-бандлов между собой блокируется предусловием из карточки F12 (показывать заглушку
  «нет собственного плана» честно, а не пустые нули).
- Сама шторка F12 — оверлей сцены «Поля» (§4); здесь, в «Сравнении», — дельта ЧДД по времени
  и список разошедшихся скважин.

## 8. Инспектор

Один контейнер (R8), ширина `--size-card-max`, заголовок + крестик, Escape закрывает, фокус
возвращается на вызвавший элемент (поведение F5 сохраняется). Содержимое по контексту:

| Контекст | Содержимое | Источник сегодня |
|---|---|---|
| Скважина | параметры шага, три спарклайна истории, соседи по λ (клик переводит выделение), участок, окно λ, трасса решения | `views/WellCard` — как есть |
| Сценарий | статус, провенанс, ключевые поля доверия, кнопка «сделать активным» | поповер `ScenarioBadge` |
| Правило (позже, с F15 в «Решениях») | формулировка, дельта ЧДД, доля, состояние флага | строка AblationTable |

Инспектор не модален, сцену не перекрывает и не запирает фокус. На узких окнах (<1200px)
допустим оверлей поверх правого края сцены — единственное разрешённое перекрытие.

## 9. Ось времени

Одна строка на всю ширину, всегда видима, во всех пространствах (требование F7 сохраняется).

```text
│ 2007────2009────2011────2013────2015────2017────2019────2021────2023────2025 │
│  ·в27 ·з41      ·о12          засечки: ввод, перевод под закачку, остановка  │
│ [⏮][▶][⏭]  ────────●──────────────────  [1×|4×|16×]  январь 2007 · шаг 1/225 │
```

- Транспорт сокращается с 5 кнопок до 3: назад-на-шаг / play / вперёд-на-шаг; «в начало»,
  «в конец» и годовые прыжки — клавишами (уже есть в F10: стрелки, [, ]) и кликом по шкале лет.
- Состояние `playing/speed` — одно, из контекста (R3).
- Засечки событий берутся из данных (ввод, перевод, остановка) — требование F7; у демо-бандла
  событий нет (находка в `DONE.md`) — шкала честно пустая, без выдуманных меток.

## 11. Клавиши

Существующие (F10) не меняются. Новые не конфликтуют.

| Клавиша | Действие | Статус |
|---|---|---|
| Пробел | воспроизведение / пауза | есть (F10) |
| ← → | шаг назад / вперёд | есть (F10) |
| [ ] | год назад / вперёд | есть (F10) |
| Ctrl/Cmd+K | палитра | есть (F10) |
| Escape | закрыть инспектор / поповер / палитру | есть частично |
| 1 2 3 4 | Поле / История / Решения / Деньги | новое (R12) |
| I | открыть/закрыть инспектор последнего объекта | новое (R12) |

Буквенно-цифровые клавиши действуют только когда фокус не в поле ввода (палитра, редактор
ограничений, поиск) — иначе набор текста будет переключать пространства.

Палитра дополняется командами: «Поле», «История», «Решения», «Деньги», «Матрица», «Миниатюры»,
«Таблица», «Рейтинг», «Сравнение», «Ограничения». Ввод остаётся единственным местом, где «всё
можно» — интерфейсу это позволяет оставаться пустым.

## 12. Изменения слоя токенов и CSS

Добавить (имена — ориентир):

- `--size-nav` — ширина левой навигации;
- `--h-header`, `--h-strip`, `--h-timeaxis` — высоты полос каркаса;
- `--z-popover` — если ⚙/легенда-поповер не покрываются существующими `--z-*`.

Изменить:

- область сцены больше не ограничивается `--size-map-max`; токен остаётся только там, где он
  про карточку, либо удаляется вместе с ограничением (R10);
- `console.css`: grid-template-areas вместо стека и `:has()`.

Не добавлять: новых цветов, радиусов, теней, анимаций. Палитра величин, плотность, моноширинные
цифры — всё из F1 без изменений. Каждая новая анимация обязана кодировать величину — правило
пакета действует.

## 13. Состояния

- **Загрузка/ошибка/пусто** — существующий `ViewStatus` во всех пространствах; пространство
  декларирует свой набор датасетов (К12), и статус считается по нему, а не по каждому компоненту
  отдельно.
- **Нет собственного плана** (F12/F16 ещё не разблокированы данными) — под-табы «Сравнение»
  и «Ограничения» показывают честную заглушку с причиной, не пустые таблицы.
- **Синтетика** — статус-чип янтарный всегда (см. §2), пространства работают как есть.
- **Прогон OPM с нарушениями валидации** — чип янтарный «число не заявляемо» (случай G7);
  зелёный чип возможен только при чистой валидации.
- **prefers-reduced-motion** — морфинг и развороты мгновенные; правило действует на все
  анимации каркаса.
- **Узкое окно** (<1200px): навигация сжимается в верхнюю строку-сегмент, инспектор — оверлей;
  ось времени не скрывается никогда.

## 14. Сценарий защиты (проверка компоновки на 7 минутах)

1. Открытие: «Поле», граф связности (главный вид по §12.3) — жюри сразу видит то, чего нет
   у других команд; чип статуса честно виден. Пробел — поле живёт.
2. Клик «Карта» и обратно — морфинг доказывает тезис про λ (3 секунды, без слов): соседи по
   карте расходятся, связанные через пласт сближаются.
3. Клавиша 2 — «История», матрица: 18 лет одним экраном, волна обводнения.
4. Клик по аномальной строке — инспектор скважины: трасса решения, соседи по λ.
5. Клавиша 3 — «Решения»: путь этой скважины в иерархии, числа меняются с шагом.
6. Клавиша 4 — «Деньги»: рейтинг, сравнение с базой (когда будет план — шторка F12).
7. Ctrl+K → «Демо» — срежиссированный пролёт F13 по тем же пространствам.

Каждый переход — один жест; ни одного скролла; ось времени и статус доверия на экране все
7 минут.
