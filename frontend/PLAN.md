## Непреложные правила (сводка, полные тексты в карточках)

1. Интерфейс не вычисляет — все величины готовыми из артефакта (§12.1).
2. Литералы `225`, `224`, `103`, `371` в коде запрещены — оси из данных.
3. Терминальный шаг: 225 управляющих дат при 224 интервалах; последний шаг — состояние без интервала и денег, и это подписано (§2.2). Обязательно для F4, F6, F14.
4. Запрещено: градиенты, свечения, стекло, bento, скругления >4px, тени, hover-смещения, анимации без величины.
5. `magic-mcp` (21st) — только служебное: палитра, ползунки, табы, тултипы, тосты. Карта, граф, хронокарта, графики — вручную SVG/canvas.
6. `contracts/` не трогаем. Основная работа в `frontend/`; точечные дополнения экспортёров в `ui/` — отдельная задача D1 с пометкой для Савелия (см. PLAN_DATA.md).

8. Код: без комментариев, импорты сверху, ≤250 строк/файл, именованные экспорты, i18n ru+en синхронно, обе темы.
9. Коммиты — только по команде пользователя. Границы коммитов — одна задача = один коммит, сообщения предложены в конце файла.
10. Приёмка задачи — раздел «Приёмка» её карточки дословно, не вольная трактовка.

## Протокол закрытия волны (выполняю сам после обоих агентов)

1. `npx --yes node@22.11.0 node_modules/vitest/vitest.mjs run` — зелёный полностью.
2. `npx tsc --noEmit` — чисто.
3. `npm run build` — проходит.
4. Grep-гейты: `radius-pill|translateY(-2px)|dot-grid` — ноль вхождений (после W1); `\b(225|224|103|371)\b` по `src/**/*.ts*` — ноль вне тестовых фикстур; `box-shadow|linear-gradient|radial-gradient|backdrop-filter` в новых стилях — ноль (кроме токен-файла, если тень запрещённая — её и там нет).
5. i18n: тест синхронности словарей зелёный, новые ключи в ru и en.
6. Скриншоты приёмки через playwright на dev-сервере (порт 5199), в обеих темах для затронутых экранов; складываются в `frontend/shots/` (в git не идут).
7. Только после этого стартует следующая волна.

## Инструменты по волнам

- **W1**: скилл `ui-ux-pro-max` (плотность data-dense-консоли, пары шрифтов — снято заранее: Inter + JetBrains Mono, паттерн «mono для чисел, sans для подписей»), скилл `frontend-design` для сдержанности. Шрифты кладутся локально в `public/fonts` (woff2, cyrillic+latin через unicode-range, как Inter).
- **W2–W4, W7**: скилл `dataviz` перед каждым графиком/шкалой (хронокарта, спарклайны, главный график, стена) — форма, цветовые шкалы, легенды, поведение в обеих темах.
- **W6**: `magic-mcp` (MCP `21st`) — генерация каркаса командной палитры, затем пересадка на наши токены; это единственное разрешённое ему место наряду с ползунком скорости.
- **Все волны**: playwright MCP для скриншотов приёмки; `impeccable` — финальный проход W9 по консоли целиком.

## Риски и обход

| Риск | Обход |
|---|---|
| Два агента в одном дереве | Непересекающееся владение файлами в таблице волн; `App.tsx` всегда у одного; сборку и полный прогон делаю только я на закрытии волны |
| D1 перегенерирует `public/data` посреди работы | Тесты фронта живут на фикстурах, не на `public/data`; валидаторы терпимы к дополнительным полям; перегенерация — последним шагом D1 |
| F7 ломает тесты всех видов | Соло-волна; карточка запрещает менять состав `TimelineContext`/`ScenarioContext` — только перекомпоновка; тесты адаптируются, не удаляются |
| Node 24 локально валит тесты | Всегда пиновый прогон `npx --yes node@22.11.0 …`; это известная особенность, не поломка |
| Шрифт не скачивается | Фолбэк-стек `ui-monospace, 'Cascadia Mono', Consolas, monospace` обязателен в токене независимо от исхода |
| `origin/main` уехал (`64b7cbd`) | Работа локальна во `frontend/`, пересечений с `optimizer/` нет; ребейз — по команде пользователя |
| Синтетика в `public/data` | Локально данные демонстрационные — это нормально для разработки; D1 расширяет экспортёры так, чтобы реальный артефакт (путь `ui/base_artifact.py`) получил те же поля |
