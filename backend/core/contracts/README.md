# Контракты данных

Исполняемым источником истины являются типы Python в этом каталоге. Этот файл — их краткая карта;
при расхождении прав код.

| Модуль | Контракт |
|---|---|
| `schedule.py` | расписание, управляющее событие и ось скважин |
| `response.py` | `StateAtDate` на датах дека и `IntervalResponse` на интервалах управления |
| `constraints.py` | ограничения и результаты валидации |
| `economics.py` | таблица ЧДД и денежные компоненты |
| `run_artifact.py` | сериализуемый результат прогона для UI |
| `simulation.py` | запрос и результат OPM-прогона |
| `connectivity.py` | матрица связности и группы скважин |
| `config.py`, `policy.py` | конфигурация и трасса правил |

## Неподвижные правила

- Управляющих дат 225, но подтверждённых интервалов 224: терминальная дата не несёт интервала
  и денежных потоков.
- Ось скважин, единицы и обязательность полей определяются конструкторами и тестами модулей.
- Семантический хеш расписания создаётся единым каноном из `hashing.py`.
- Финальный артефакт допускается только после успешной валидации динамики и расчёта ЧДД.

Эталонный расчётчик и нормативы организаторов находятся в `../../../../docs/models/CHDD_PYTHON/`.
