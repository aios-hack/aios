# Демо-сценарий на защиту

Показ укладывается в ~2 минуты. Демонстрационный запуск **воспроизводит готовый
артефакт**, а не считает заново: интерфейс читает JSON из `public/data/`,
собранный заранее.

## Подготовка до выхода к жюри

```
.venv/bin/python -m backend.presentation.ui_export.demo     # собирает весь набор в frontend/public/data/
cd frontend
npm run dev                     # или npm run build && npm run preview
```

Открыть вкладку **«Граф влияния»**, светлая тема, русский язык. По умолчанию
открыт сценарий `base`, и плашки синтетики в шапке быть **не должно**: она
показывается только при `meta.synthetic === true`, то есть на
`whatif-injection-cut`. Проверить обратное — переключиться на демо-сценарий в
библиотеке и убедиться, что плашка появилась.

**Каталог `frontend/public/data/` не входит ни в git, ни в образ** — он исключён
`frontend/.gitignore` и `.dockerignore`, а генерации нет ни в `Dockerfile`, ни в
`docker/entrypoint.sh`. Поэтому команду выше надо выполнить на той машине, с
которой идёт показ: без неё интерфейс поднимется пустым.

## Про данные — сказать сразу, одной фразой

Набор смешанный, и путать сценарии нельзя. Сценарий `base` — **настоящий**:
отклик настоящего прогона OPM, ЧДД по Методике `11 873.68 млн руб`, сходящийся с
эталонным расчётчиком организаторов до машинного нуля; в метаданных
`provenance: "model-z-base-run"`, `synthetic: false`. Исключение внутри него одно
и помечено отдельно — граф связности: `lambda_measured: false`, нулевая матрица,
рёбер нет. Сценарий `whatif-injection-cut` — **демонстрационный**: масштаб
настоящий (103 скважины из `WELSPECS`, 225 управляющих шагов при 224 интервалах),
физика и экономика сгенерированы детерминированно с фиксированным seed,
`provenance: "synthetic-demo"`, в интерфейсе постоянная плашка. **Число ЧДД на
демо-сценарии смысла не имеет и настоящим не притворяется.**

## Порядок показа

### 1. Граф влияния λ — 40 секунд, главный тезис

Открыт по умолчанию. Это единственная картинка, которая за десять секунд
объясняет, чем мы отличаемся.

> «Расстояние между скважинами здесь задаёт не метрика месторождения, а λ —
> межскважинная связность. Пространственная близость не означает
> гидродинамическую связь, и мы её не предполагаем, а измеряем планом
> эксперимента: половина нагнетательных на повышенный режим, половина на
> пониженный, дальше регрессия отклика на столбцы плана.»

**Говорить в прошедшем времени про λ нельзя.** Код измерения написан и покрыт
тестами (`connectivity/`), но серия возмущённых прогонов OPM не выполнялась ни
разу: в демонстрационном наборе λ сгенерирована вместе с остальной синтетикой, а
в бандле базового прогона (`ui.base_artifact`) её вовсе нет — там нулевая
матрица, `lambda_measured: false` и пустой граф. Формулировка, которую можно
произносить: «механизм измерения готов и показан, самого замера на настоящих
прогонах мы ещё не делали». Вопрос жюри «а λ у вас измерена?» — ответ «нет,
измеритель есть, кампания прогонов впереди».

- Показать плашку окна: матрица относится к конкретному окну. Связность не
  вечная: фонд нагнетательных растёт с 27 до 41, поэтому λ и несёт область
  применимости.
- Потянуть **порог λ** — слабые связи исчезают, остаётся скелет участков.
  «Нарезка на участки замышлена из λ, а не из карты» — именно замышлена:
  алгоритм `Groups = f(λ)` до настоящего замера остаётся гипотезой
  (`docs/context/07_concept.md` §6).
- Кликнуть узел — подсвечиваются соседи выше порога, справа панель: участок,
  число соседей.

### 2. Карта — 15 секунд, вторая по важности

Вкладка **«Карта»**.

> «Вот тот же фонд в плане, в индексах сетки. Сравните с графом: соседи по карте
> и соседи по λ — разные множества. Ради этого граф и главный.»

Переключить пласт (Все / Пласт 1 / Пласт 2) — принадлежность слоям из `K1 K2`
в `COMPDAT`, не догадка.

### 3. Шаги — 25 секунд, состояние фонда во времени

Вкладка **«Шаги»**.

- Потянуть бегунок к середине горизонта. Обновляются агрегаты поля: отбор,
  закачка, компенсация, накопленный ЧДД, число действующих скважин.
- Отметить: **невведённые скважины подписаны как невведённые**, а не как
  остановленные. 22 скважины входят в работу внутри горизонта — это программа
  месторождения, а не решение агента.
- Последний шаг (225-й) подписан как состояние без месяца: интервалов 224.

### 4. Карточка скважины с Trace — 25 секунд, объяснимость

Кликнуть строку любой работающей скважины.

> «Параметры на шаге t, включая отношение факт/цель. Ниже — сработавшее правило
> из Trace с числами, на которых оно сработало, и текст объяснителя.»

Главное: решение не «чёрный ящик», у каждого есть правило и входные числа.
Закрыть по Esc.

### 5. Вклад в ЧДД — 20 секунд, «кто жрёт деньги»

Вкладка **«Вклад в ЧДД»**. Отсортировать по возрастанию — наверху отрицательные.

> «Это поскважинное разложение из расчёта, интерфейс не считает ничего сам.»

Переключить **«До налога» / «С распределённым налогом»**: налог на прибыль
скважинного значения не имеет и распределяется соглашением. Подпись меняется
вместе с режимом — молча смешивать эти две величины нельзя.

### 6. Сценарии — 15 секунд, финал

Вкладка **«Сценарии»**.

- В библиотеке два артефакта. У одного бейдж **«Сдан»** и число ЧДД, у второго —
  **«Что если»** и ЧДД пустой: `final_npv` не пустой ровно у одного артефакта,
  прошедшего финальную сдачу. Так в интерфейсе видно, какой вариант заявлен.
- Переключить на «что если» — все виды перечитывают другой артефакт.

> «Сценарии — это библиотека готовых артефактов, между которыми переключаются.
> Поэтому демонстрация укладывается в минуты: мы воспроизводим, а не считаем.»

объяснимость) не выбрасывать.

## Запасной вариант

Если дев-сервер не поднимается на площадке — показывать заранее записанное
ускоренное видео этого же сценария [10.08 22:29]. Порядок и реплики те же.
