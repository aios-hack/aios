# Визуальная система: источник — сайт хакатона

Снято с `https://blueskyresearch.ru/hackathon_aios/` 16.08.2026 через Playwright: значения взяты из `:root` и `getComputedStyle`, не на глаз. Это база фирменного стиля организаторов, от которой отталкивается интерфейс `ui/web`.

Файл — справочник происхождения. Рабочие токены живут в `src/theme/tokens.css`; при расхождении правится он, а эта таблица описывает, откуда взялось значение.

## Цвет

Стратегия — restrained: белый холст, один насыщенный синий несёт всю идентичность, акцент занимает меньше десятой части поверхности.

| Роль | Значение | Где применяется |
|---|---|---|
| `--accent` | `#232DCD` | Основной синий: кнопки, ссылки, активные вкладки, обводка |
| `--accent-2` | `#3D47DA` | Ховер, второй шаг градиента |
| `--accent-3` | `#5D68E4` | Третий шаг, вспомогательные метки |
| `--accent-4` | `#8891EE` | Самый светлый, крупные заливки |
| `--accent-dim` | `rgba(35,45,205,0.08)` | Подложка активного состояния |
| `--accent-dim2` | `rgba(35,45,205,0.14)` | Подложка ховера |
| `--status-ok` | `#10A345` | Единственный не-синий: успех, зелёная точка |

Нейтрали заданы прозрачностями чернильного `#0B0C14`, а не отдельными серыми — ступени всегда согласованы с фоном:

| Роль | Значение | Назначение |
|---|---|---|
| `--fg1` | `#0B0C14` | Заголовки, основной текст |
| `--fg2` | `rgba(11,12,20,0.66)` | Вторичный текст, подписи |
| `--fg3` | `rgba(11,12,20,0.42)` | Третичный, метаданные |
| `--fg4` | `rgba(11,12,20,0.22)` | Разделители, выключенное |
| `--bg` | `#FFFFFF` | Холст |
| `--bg-subtle` | `#F4F6FB` | Чередующиеся полосы секций |
| `--bg-section` | `#F8FAFD` | Фон секции, ещё светлее |
| `--surface` | `rgba(255,255,255,0.92)` | Карточки поверх точечного фона |

Границы тонированы синим, а не серым — это заметно отличает систему от нейтрального дефолта:
`--border: rgba(35,45,205,0.12)`, `--border-strong: rgba(35,45,205,0.22)`, `--border-subtle: rgba(11,12,20,0.08)`.

Тени тоже синие, не чёрные:
`--shadow-1: 0 2px 8px rgba(35,45,205,0.06), 0 1px 2px rgba(11,12,20,0.04)`,
`--shadow-2: 0 6px 24px rgba(35,45,205,0.10), 0 2px 6px rgba(11,12,20,0.05)`,
`--shadow-accent: 0 6px 24px rgba(35,45,205,0.28)` — только под акцентной кнопкой.

**Тёмной темы у источника нет.** Наш интерфейс обязан иметь обе (требование к `ui/web`), поэтому тёмная выводится нами, а не копируется: холст уводится в сторону `#0B0C14`, акцент осветляется до читаемого на тёмном (иначе `#232DCD` на тёмном фоне не проходит по контрасту), нейтрали инвертируются прозрачностями белого.

## Типографика

Одна гарнитура в шести весах — контраст берётся весом и размером, а не второй гарнитурой.

- Основная: **Inter** (`-apple-system`, `BlinkMacSystemFont`, `Segoe UI` в откате)
- Заголовок сайта организаторов набран **GraphikTT** — это шрифт их шаблона, не часть системы хакатона; не тянем.
- `--mono` у источника указывает на Inter — то есть моноширинного в системе фактически нет. Для чисел, хешей и кодов нам нужен настоящий моноширинный: это осознанное расширение базы.

Шкала (все значения — из `:root` источника):

| Токен | Значение |
|---|---|
| `--fs-display` | `clamp(56px, 7.2vw, 92px)` |
| `--fs-h2` | `clamp(28px, 3.2vw, 40px)` |
| `--fs-h3` | `18px` |
| `--fs-h4` | `15px` |
| `--fs-lead` | `clamp(17px, 1.3vw, 19px)` |
| `--fs-body` | `15px` |
| `--fs-sm` | `13px` |
| `--fs-xs` | `12px` |

Веса: 300 / 400 / 500 / 600 / 700 / 800. Заголовки — 800, кнопки и активные вкладки — 600.

Интерлиньяж: `--lh-tight: 1.08` (display), `--lh-snug: 1.3` (заголовки), `--lh-normal: 1.55` (текст), `--lh-loose: 1.7` (длинная проза).

Трекинг: `--tracking-display: -0.038em`, `--tracking-tight: -0.025em`, `--tracking-h3: -0.01em`, `--tracking-mono: 0.08em`, `--tracking-eyebrow: 0.14em`.

Замеренный H1: 92px / 800 / lh 88.32px / ls −3.496px.

## Форма и ритм

- Скругления: `--radius: 16px` (карточки, панели), `--radius-sm: 8px` (мелкие элементы), `--radius-pill: 999px` (**все** кнопки и метки — характерная черта системы, кнопок с прямыми углами у источника нет)
- Вертикальный ритм секций: `80px` сверху и снизу — основной шаг, `56px` — уплотнённый. Два шага, не непрерывная шкала.
- Горизонтальные поля контейнера: `20px`

## Кнопки

Три варианта, все со скруглением 999px и весом 600 при 15px:

| Вариант | Фон | Текст | Отступы | Обводка | Тень |
|---|---|---|---|---|---|
| `primary` | `#232DCD` | белый | `14px 28px` | нет | `0 6px 24px rgba(35,45,205,0.28)` |
| `outline` | прозрачный | `#232DCD` | `12.5px 28px` | `1.5px solid rgba(35,45,205,0.22)` | нет |
| `white` | белый | `#232DCD` | `14px 28px` | нет | `0 6px 24px rgba(0,0,0,0.18)` |

Метка (`pill`): фон `rgba(255,255,255,0.92)`, отступы `8px 14px`, 11px, трекинг `0.88px`, обводка `1px solid rgba(35,45,205,0.12)`, скругление 999px.

## Фон

Опознавательный знак системы — **точечная сетка**, а не градиентная заливка:

```css
background-image: radial-gradient(circle, rgba(35,45,205,0.08) 1px, transparent 1px);
```

Варианты: на акцентных поверхностях точки белые — `rgba(255,255,255,0.10)`; у карточек-призраков вместо точек линейная сетка `rgba(35,45,205,0.043)` по обеим осям.

Градиенты применяются ровно в двух местах и оба раза как заливка акцентного блока, никогда как декор и никогда в тексте:
`linear-gradient(135deg, #232DCD 0%, #1A23B5 100%)` — финальный CTA и акцентная карточка.

## Движение

Кривые: `ease-out` для состояний (160–280ms), `cubic-bezier(0.4, 0, 0.2, 1)` для раскрытий и длинных проездов (360–1400ms), `cubic-bezier(0.34, 1.56, 0.64, 1)` — лёгкий перелёт для точек и переключателей (320ms).

Длительности по назначению: наведение 160–220ms, состояние компонента 200–280ms, раскрытие панели 360–460ms, появление заголовка 700ms, проезд оси 1200–1400ms.

Именованные анимации источника:

| Имя | Что делает |
|---|---|
| `ch-rise` | Появление заголовка по буквам, 700ms `cubic-bezier(0.2,0.7,0.2,1)`, forwards |
| `dot-blink` | Пульс живой точки, 1.6s ease-in-out, бесконечно: opacity 1→0.5, scale 1→0.85 |
| `cursor-blink` | Курсор тикера, 1s `steps(1)`, бесконечно |
| `kp-ring` | Расходящееся кольцо от точки: scale 0.6→1.6, opacity 0.5→0 |

Приём, который стоит перенять: **каскад по индексу** — задержка вычисляется из CSS-переменной элемента, `calc(var(--mi, 0) * 180ms + 600ms)`. Даёт последовательное проявление ряда без JS.

Ветки `prefers-reduced-motion` в CSS у источника нет, но в JS она есть: вся интерактивная графика проверяет `reduce` и `isFinePointer` до запуска. В CSS её нужно добавить самим.

### Реакция на указатель

Это не CSS-свечение, а canvas-система частиц в hero. Разобрана по исходнику, параметры точные:

| Параметр | Значение | Смысл |
|---|---|---|
| Плотность | `(W×H)/9000`, зажато в 10…24 | Число точек от площади, не фиксированное |
| Радиус связи | `110px` | Ближе этого — точки соединяются линией |
| Радиус отталкивания | `130px` | Зона реакции на курсор |
| Сила отталкивания | `(1 − d²/R²) × 0.55` | Спадает квадратично к краю зоны |
| Затухание скорости | `0.985` за кадр | Точки не разлетаются |
| Сглаживание курсора | `0.18` | Позиция догоняет мышь, не прыгает |
| Нарастание эффекта | `0.08` | Появление и угасание реакции |
| Дрейф покоя | `±0.04` при затухании | Точки не замирают совсем |
| Скорость времени | `+0.0065` за кадр | Общая фаза мерцания |
| DPR | `min(devicePixelRatio, 1.5)` | Потолок разрешения ради кадров |

Оптимизация, которую стоит перенять: **пространственная сетка** с ячейкой в радиус связи — вместо перебора всех пар точек проверяются только соседние ячейки. При 24 точках это незаметно, но при плотном графе скважин уже принципиально.

Дисциплина, которую переносим обязательно: canvas останавливается по `visibilitychange` и когда блок ушёл с экрана; указатель обрабатывается только при `pointer: fine`; при `prefers-reduced-motion` вся система не стартует вовсе.

Поверх canvas — слой SVG с концентрическими кольцами, пульсирующими через `<animate>` (радиус `62→74→62`, прозрачность `0.22→0.05→0.22`, период 4s), и узлами, которые ведёт лёгкий параллакс от той же позиции курсора.

### Состояния наведения

Единая логика: подъём на 2px, усиление тени, тонирование границы акцентом.

- Карточка: `border-color` → `--border-strong`, `translateY(-2px)`
- Основная кнопка: фон → `--accent-2`, тень → `0 10px 36px rgba(35,45,205,0.36)`
- Кнопка-контур: фон → `--accent-dim`, граница → `--accent`
- Стрелка внутри кнопки: `translateX(4px)` — направление действия
- Ячейка статистики: едва заметная подложка `rgba(35,45,205,0.024)`, число `scale(1.04)`

Приём, который стоит взять: **элемент внутри кнопки живёт своей анимацией** — стрелка уезжает вправо, иконка увеличивается. Это дороже одного `background` и заметно оживляет интерфейс.

## Компоновочные приёмы

Снято с прокрученных секций — при `fullPage` они пустые, потому что проявляются по скроллу.

**Эйбрау секции.** Короткая линия `—` акцентным синим, затем заглавными 11–12px с трекингом `0.14em`: `— СУТЬ ХАКАТОНА`, `— ЭТАПЫ`. Ставится над каждым H2 и служит навигационной меткой.

**Карточка-схема.** Слева от текста — панель с линейной сеткой на фоне, в ней граф: узлы как пилюли с обводкой `1.5px` акцентом, подписи моноширинным заглавным (`ORCH`, `INFRA`, `PAD_01`, `WELL_01`), связи пунктиром. Углы панели помечены уголками-скобками. Заголовок панели — моноширинный `// AIOS.NETWORK` слева и счётчик `NODES · 9` справа, оба 11px, цвет `--fg3`. Прямой прообраз нашего графа влияния.

**Таблица «ключ — значение».** Метка слева заглавными 11px акцентом с трекингом, значение справа обычным текстом, между строками — только тонкий разделитель `--border-subtle`, без заливки. Плотный способ подать параметры.

**Список критериев.** Двухколоночная сетка карточек с заливкой `--bg-subtle`, у каждой буквенный маркер акцентом слева (`A`…`H`) и, при необходимости, метка-пилюля (`ТРЕК 2`) перед текстом.

**Ось времени.** Горизонтальная линия с точками-засечками, подписи под ними заглавными 11px; активная засечка выделена акцентом и подчёркнута короткой чертой. Линия «проезжает» слева направо за 1200–1400ms, точки проявляются каскадом по индексу.

**Ранжирование карточками.** Ряд из трёх: первая — сплошная заливка акцентом с белым текстом, остальные — белые с обводкой и акцентным числом. Число набрано крупно (около 40px, вес 800), рядом кружок с порядковым номером. Годится для нашего рейтинга скважин по вкладу в ЧДД: первое место читается мгновенно, без легенды.

**Итоговая строка справа.** Над рядом карточек — метка трека слева, сумма справа (`Итого 400 000 ₽`) обычным весом с выделением числа полужирным.

## Что берём, а что нет

Переносим: палитру целиком, шкалу типографики, скругления, ритм 80/56, точечный фон, кривые и длительности движения, каскад по индексу, форму кнопок и меток.

Не переносим: логотип организатора, GraphikTT, маркетинговую структуру страницы (hero во весь экран, финальный CTA-блок, счётчики). Наш интерфейс — рабочий инструмент: те же материалы, другая плотность.

Добавляем от себя, потому что у источника этого нет: тёмная тема, настоящий моноширинный шрифт для чисел и хешей, `prefers-reduced-motion`, состояния фокуса для клавиатуры, плотная сетка данных.

## Расхождение с тем, что было в интерфейсе

Состояние `tokens.css` до переноса — и почему каждый пункт меняется:

| Что | Было | Стало | Причина |
|---|---|---|---|
| Акцент | `#0D6EFD` | `#232DCD` | Дефолтный синий Bootstrap заменяется фирменным |
| Гарнитура | `Segoe UI` | `Inter` | Системный шрифт Windows не имеет отношения к системе |
| Скругления | `4px` / `8px` | `8px` / `16px` / `999px` | У источника нет прямоугольных кнопок |
| Границы | `#D7DBE0` серый | `rgba(35,45,205,0.12)` | Границы тонируются акцентом |
| Тени | чёрные | синие | `rgba(35,45,205,…)` вместо `rgba(28,39,51,…)` |
| Шкала кегля | 12–22px, 5 ступеней | 11–92px, 9 ступеней | Нет крупного размера для заголовков |
| Веса | 400/500/600 | 300…800 | Заголовкам нужен 800 |
| Фон | плоский `#F6F7F9` | точечная сетка | Опознавательный знак системы |

**Палитра групп остаётся радужной.** `--color-group-1…6`, слои карты, типы скважин — это категориальное кодирование данных, где различимость важнее фирменности; шесть оттенков одного синего неразличимы на графе. Меняются интерфейсные цвета, не цвета данных. Исключение — тип скважины: нагнетательная/добывающая уходят в акцентный синий и `--status-ok`, потому что это бинарная оппозиция, а не категория.
